# Healthcare App

A modern healthcare application interface built using React, TypeScript, and Vite, focused on creating a clean and user-friendly patient experience. This project demonstrates responsive UI development, reusable component architecture, and modern frontend development practices.

## Overview

The Healthcare App is a frontend healthcare platform designed to provide users with an intuitive and visually appealing healthcare experience. The project focuses on delivering a smooth onboarding and splash screen flow with modern UI/UX principles.

The application is built with:

* React
* TypeScript
* Vite
* CSS / Modern Styling

This project was inspired by a healthcare splash screen design concept from Figma and implemented as a functional frontend application.

## Features

* Clean and responsive healthcare-themed UI
* Modern splash screen and onboarding experience
* Component-based frontend architecture
* Fast development environment powered by Vite
* Type-safe development using TypeScript
* Organized project structure for scalability and maintainability

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/vijaykrishna68/Healthcare-App.git
```

### Navigate to the Project Folder

```bash
cd Healthcare-App
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

The application will start locally on the Vite development server.
